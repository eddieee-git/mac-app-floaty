Floaty 0.2.4예요. 새 버전이 나오면 Floaty를 쓰지 않을 때 알아서 설치해요.

[English below](#english)

## 설치와 업데이트

- **0.2.3을 쓰고 있다면**: 메뉴바 아이콘 메뉴의 **새 버전 0.2.4 설치…**를 한 번 눌러 주세요. 0.2.3은 자동 설치가 꺼져 있어서 이번 한 번만 직접 눌러야 해요. 0.2.4부터는 알아서 설치돼요.
- **0.2.1이나 0.2.2를 쓰고 있다면**: Floaty가 새 버전을 알려 줘요. **업데이트**를 누르면 받아서 바꾼 뒤 다시 켜요.
- **0.2.0 이전이거나 처음 설치한다면**: 아래 **Floaty-0.2.4.dmg**를 내려받아 Floaty를 응용 프로그램 폴더로 끌어다 놓으세요. 이전 버전을 쓰고 있었다면 먼저 메뉴바 아이콘 → **Floaty 종료**로 꺼요. 스티커와 설정은 그대로 남아요.
- 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요. 자세한 내용은 [설치 안내](https://github.com/eddieee-git/mac-app-floaty/blob/main/docs/install.md)를 보세요.

## 바뀐 점

- **자동 설치 기본 켬**: Floaty를 쓰고 있지 않을 때(다른 앱으로 넘어갔을 때, 아니면 한 시간마다) 새 버전을 받아 바꿔 넣고 다시 켜요. 설치 전에 서명, SHA-256, 코드 서명을 모두 확인하는 것은 그대로예요.
- **바로 설치**: **업데이트 확인…**이나 **새 버전 X 설치…**를 누르면 묻는 창 없이 바로 설치해요.
- 자동 설치는 설정 → 일반 → 업데이트에서 끌 수 있어요. 끄면 새 버전이 있을 때 버전마다 한 번 알려 줘요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 13 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.

## English

Floaty 0.2.4 installs new versions on its own while you aren't using it.

**Installing and updating**
- On 0.2.3: click **Install Version 0.2.4…** in the menu bar icon's menu once. Automatic installs are off in 0.2.3, so this one time is manual; from 0.2.4 on, updates install themselves.
- On 0.2.1 or 0.2.2: Floaty tells you about the new version; click **Update**.
- From 0.2.0 or a new install: download **Floaty-0.2.4.dmg** below and drag Floaty into Applications (quit the old version first; your stickies and settings are kept). If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security. See the [installation guide](https://github.com/eddieee-git/mac-app-floaty/blob/main/docs/install.en.md).

**Changed**
- **Automatic installs on by default**: While you aren't using Floaty (when you switch to another app, or once an hour), it downloads a new version, swaps it in, and restarts. The signature, SHA-256, and code signature are still checked before installing.
- **Install right away**: Clicking **Check for Updates…** or **Install Version X…** installs without asking.
- Turn automatic installs off in Settings → General → Updates. When off, Floaty tells you about each new version once.

**Known limitations**
- Apple silicon Macs with macOS 13 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
