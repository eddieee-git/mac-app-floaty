Floaty 0.2.1입니다. 앱 안에서 바로 업데이트하는 기능과 제목 변경 단축키(F2)가 들어갔고, Esc가 더 이상 스티커를 지우지 않습니다.

## 설치와 업데이트

1. 아래 `Floaty.dmg`를 내려받아 열고, Floaty를 Applications 폴더로 끌어다 놓습니다. 이전 버전을 쓰고 있었다면 먼저 메뉴바 아이콘 → **Floaty 종료**로 끈 뒤 기존 앱을 대체합니다. 스티커와 설정은 그대로 남습니다.
2. Floaty를 실행합니다.

**처음 실행할 때 macOS 보안 경고가 나옵니다.** Apple의 유료 개발자 인증을 받지 않은 무료 앱이기 때문입니다. 경고 창을 닫은 뒤 **시스템 설정 → 개인정보 보호 및 보안**의 아래쪽에서 **그래도 열기**를 누르면 됩니다. 자세한 내용은 [설치 안내](https://github.com/eddieee-git/mac-app-floaty/blob/main/docs/install.md)를 보세요.

**이번이 마지막 직접 설치입니다.** 0.2.1부터는 새 버전이 나오면 Floaty가 알려 주고, **업데이트**를 누르면 받아서 바꾼 뒤 다시 켭니다. 이때는 보안 경고가 다시 나오지 않습니다.

## 바뀐 점

- **앱 안에서 업데이트:** 하루에 한 번 새 버전을 확인하고, 업데이트를 누르면 받아서 바꾼 뒤 다시 켭니다. 받은 파일은 서명을 확인한 뒤에만 설치합니다. 설정 → 일반에서 자동 확인을 끌 수 있고, 메뉴바의 **새 버전 확인…**으로 언제든 확인할 수 있습니다. 인터넷은 이 확인에만 쓰며 스티커 내용은 보내지 않습니다.
- **제목 변경 단축키:** 스티커에서 F2를 누르면 제목을 고칩니다. 설정 → 단축키에서 바꾸거나 끌 수 있습니다.
- **Esc는 최소화:** 전에는 Esc를 누르면 스티커가 지워졌습니다. 이제는 최소화합니다.
- **작게 최소화:** 최소화하면 폭까지 줄어 제목 앞부분과 펼치기 버튼만 남습니다. 펼치면 원래 크기로 돌아갑니다.
- **⌘⌫로 삭제:** 스티커에서 ⌘⌫를 누르면 한 번 묻고 휴지통으로 옮깁니다(빈 스티커는 묻지 않음).
- **휴지통 관리 메뉴:** 메뉴바의 스티커 관리 바로 아래에서 휴지통을 바로 엽니다.

## English

Floaty 0.2.1 adds in-app updates and a rename shortcut (F2), and Esc no longer deletes a sticky.

- **In-app updates:** Floaty checks for a new version once a day; click **Update** to download it, replace the app, and restart. The download is installed only after its signature is verified. Turn off automatic checks in Settings → General, or check any time with **Check for Updates…** in the menu bar. The internet is used only for this check; nothing about your stickies is sent.
- **Rename shortcut:** Press F2 in a sticky to rename it. Change or turn it off in Settings → Shortcuts.
- **Esc collapses:** Esc used to delete the sticky. It now collapses it, down to a small chip with the start of the title.
- **Delete with ⌘⌫:** Moves the sticky to the Trash after one confirmation.
- **Manage Trash menu:** Opens the Trash directly, right below Manage Stickies.

Download `Floaty.dmg` below, open it, and drag Floaty to the Applications folder (quit the old version first; your stickies and settings are kept). macOS shows a security warning the first time because Floaty isn't notarized: close it, then click **Open Anyway** in **System Settings → Privacy & Security**. This is the last manual install: later versions arrive through the in-app updater without the warning. See the [installation guide](https://github.com/eddieee-git/mac-app-floaty/blob/main/docs/install.en.md) and the [changelog](https://github.com/eddieee-git/mac-app-floaty/blob/main/CHANGELOG.en.md).

Requires a Mac with Apple silicon and macOS 13 or later.
