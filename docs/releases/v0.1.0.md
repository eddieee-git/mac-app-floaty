Floaty 첫 배포 버전입니다.

## 설치

1. 아래 `Floaty.dmg`를 내려받아 열고, Floaty를 Applications 폴더로 끌어다 놓습니다.
2. Floaty를 실행합니다.

**처음 실행할 때 macOS 보안 경고가 나옵니다.** Apple의 유료 개발자 인증을 받지 않은 무료 앱이기 때문입니다. 경고 창을 닫은 뒤 **시스템 설정 → 개인정보 보호 및 보안**의 아래쪽에서 **그래도 열기**를 누르면 됩니다. 자세한 내용은 [설치 안내](https://github.com/eddieee-git/Floaty/blob/main/docs/install.md)를 보세요.

## 요구 사항

- Apple 실리콘 Mac (M1 이상)
- macOS 13 이상
