Floaty 0.2.3이에요. 업데이트 기능을 다섯 앱 공통 방식으로 바꾸고, 설정에 정보 탭을 더했어요. 스티커 기능은 그대로예요.

[English below](#english)

## 설치와 업데이트

- **0.2.1이나 0.2.2를 쓰고 있다면**: Floaty가 새 버전을 알려 줘요. **업데이트**를 누르면 받아서 바꾼 뒤 다시 켜요. 바로 확인하려면 메뉴바 아이콘 → **새 버전 확인…**을 누르세요.
- **0.2.0 이전이거나 처음 설치한다면**: 아래 **Floaty-0.2.3.dmg**를 내려받아 Floaty를 응용 프로그램 폴더로 끌어다 놓으세요. 이전 버전을 쓰고 있었다면 먼저 메뉴바 아이콘 → **Floaty 종료**로 꺼요. 스티커와 설정은 그대로 남아요.
- 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요. 자세한 내용은 [설치 안내](https://github.com/eddieee-git/mac-app-floaty/blob/main/docs/install.md)를 보세요.

## 바뀐 점

- **업데이트 설정**: 설정 → 일반의 업데이트 칸에서 자동 확인(기본 켬)과 자동 설치(기본 끔)를 따로 정해요. **지금 확인**으로 바로 확인할 수도 있어요. 전에 자동 확인을 꺼 두었다면 그대로 꺼져 있어요.
- **업데이트 확인 강화**: 받은 파일의 서명, SHA-256, 코드 서명까지 모두 확인한 뒤에만 설치해요.
- **정보 탭**: 설정에 버전, GitHub, 변경 기록, 문제 알리기, 같은 사람이 만든 다른 앱 링크가 생겼어요.
- **문구 다듬기**: 알림과 안내 문구를 부드러운 말투로 맞췄어요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 13 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.

## English

Floaty 0.2.3 moves updates to the updater shared by all five apps and adds an About tab to Settings. Sticky features are unchanged.

**Installing and updating**
- On 0.2.1 or 0.2.2, Floaty tells you about the new version; click **Update** (or menu bar icon → **Check for Updates…**).
- From 0.2.0 or a new install: download **Floaty-0.2.3.dmg** below and drag Floaty into Applications (quit the old version first; your stickies and settings are kept). If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security. See the [installation guide](https://github.com/eddieee-git/mac-app-floaty/blob/main/docs/install.en.md).

**Changed**
- **Update settings**: Settings → General has separate switches for automatic checks (on by default) and automatic installs (off by default), plus **Check Now**. If you had turned automatic checks off, they stay off.
- **Stronger update checks**: A download is installed only after its signature, SHA-256, and code signature are verified.
- **About tab**: Settings shows the version and links to GitHub, the changelog, problem reports, and other apps by the same developer.
- **Wording**: Korean alerts and messages use a friendlier tone.

**Known limitations**
- Apple silicon Macs with macOS 13 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
